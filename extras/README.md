# Kanch Glass Invoice Maker - Landing Pages

This directory contains the landing pages for the Kanch Glass Invoice Maker app, designed for GitHub Pages deployment.

## Pages Included

1. **index.html** - Main landing page with features, app preview, and call-to-action
2. **terms.html** - Terms of Service page
3. **privacy.html** - Privacy Policy page  
4. **support.html** - Support center with FAQ, documentation links, and contact form

## Features

- **Modern Design**: Glassmorphism effects and smooth animations
- **Responsive**: Mobile-first design that works on all devices
- **App-Themed**: Uses the same color palette and fonts as the Kanch app
- **Accessible**: Semantic HTML and WCAG compliant
- **SEO Optimized**: Proper meta tags and structured content

## Design Elements

- **Color Scheme**: Primary #00639A (blue), Accent #76D7C4 (teal)
- **Typography**: Inter font family for consistency with the app
- **Animations**: Smooth transitions and fade-in effects
- **Icons**: Font Awesome icons for visual appeal

## GitHub Pages Setup

To deploy these pages on GitHub Pages:

1. Enable GitHub Pages in repository settings
2. Set source to "Deploy from a branch"
3. Choose "main" branch and "/docs" folder
4. The site will be available at: `https://g-shack.github.io/Kanch/`

## Local Development

To test locally, simply open `index.html` in a web browser. All styling is embedded in the HTML files for easy deployment and maintenance.
